# "О программе" и обучение

2. Создать модальное окно «О программе» со списком возможностей
3. Добавить кнопку «Пройти обучение» в этом окне
4. Реализовать пошаговое обучение (туториал) с подсветкой элементов интерфейса

## Возможности программы (для списка в "О программе")

- **Викторины** — создание, редактирование, удаление, выбор из списка
- **Категории** — добавление, удаление, переименование категорий
- **Вопросы** — добавление, удаление, редактирование текста, ответа и стоимости
- **Медиа** — вставка изображений, видео, аудио (YouTube, URL, файлы до 100 МБ через IndexedDB)
- **Команды** — добавление, удаление, переименование, выбор текущей команды
- **Игровой процесс** — выбор вопроса из сетки, подсчёт очков, пометка использованных
- **Таймер** — обратный отсчёт с полосой (зелёный→красный), звук на последних 5 секундах, пауза
- **Режим ведущего** — кнопки «Верно/Неверно», показ ответа перед публикой
- **Случайный порядок** — перемешивание категорий и вопросов
- **Печать** — печать викторины на бумагу
- **Экспорт/Импорт** — бэкап и восстановление викторин в JSON-файле
- **Автосохранение** — всё сохраняется в localStorage/IndexedDB, восстанавливается при перезагрузке

## Шаги обучения (туториал)

Пошаговый туториал из ~8 шагов, каждый подсвечивает элемент и показывает текст:

1. **Приветствие** — «Добро пожаловать в Своя Игра! Начнём обучение.» (без подсветки)
2. **Меню** — подсветка кнопки «☰ Меню», текст: «Откройте меню для управления викторинами и настроек»
3. **Сетка вопросов** — подсветка игровой сетки, текст: «Нажмите на ячейку, чтобы выбрать вопрос»
4. **Панель команд** — подсветка панели команд, текст: «Здесь отображаются команды и их очки. Нажмите на карточку для действий»
5. **Редактор** — подсветка меню→«Редактировать», текст: «Создавайте и редактируйте категории, вопросы и медиа через редактор»
6. **Настройки** — подсветка меню→режим ведущего/таймер, текст: «Настройте таймер и включите режим ведущего для полноценной игры»
7. **Данные** — подсветка меню→экспорт/импорт, текст: «Сохраняйте викторины в файл и восстанавливайте их»
8. **Завершение** — «Готово! Приятной игры!» (без подсветки)

## Реализация туториала

Туториал — стек из шагов. Каждый шаг:
```js
{ target: "#elementId", text: "Описание шага" }
```
Если `target` отсутствует — просто показать текст по центру (для приветствия/завершения).

Подсветка: целевой элемент получает класс `.tutorial-highlight`, который добавляет `box-shadow: 0 0 0 9999px rgba(0,0,0,0.6)` на оверлее + `position: relative; z-index` чтобы элемент был поверх затемнения.

Текст шага позиционируется рядом с подсвечиваемым элементом (снизу или сверху, в зависимости от расположения).

## Верификация

1. Открыть меню → появилась кнопка «О программе»
2. Нажать «О программе» → откроется модалка со списком возможностей
3. Нажать «Пройти обучение» → запустится туториал
4. Пройти все шаги — каждый подсвечивает нужный элемент и показывает текст
5. Закрыть туториал на любом шаге
6. Проверить, что после туториала всё работает нормально
